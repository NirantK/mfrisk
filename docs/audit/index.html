Residual risks & costs (honest)

  • Web layer untested in the suite. Routes, HTMX partials, and the uPlot chart are validated by manual browser screenshots, not automated e2e. A few FastAPI TestClient smoke tests would close this — deferred (low churn, UI is thin).
  • Metrics tested on synthetic data. Formulas are pinned to closed-form answers; a single real-fund cross-check was done manually. A fixture from one cached fund would harden this.

  • No static type enforcement. Type hints are present but not checked; adding mypy/ pyright to CI is a cheap next step.
  • Out of scope (by design): observability, security, deployment hardening — per the antislop boundary, these belong to a separate production-readiness pass.
