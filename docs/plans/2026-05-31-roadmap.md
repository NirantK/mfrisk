# Roadmap & Milestones — mfrisk

_Date: 2026-05-31_

Build order favours a **working, demoable slice early**, then breadth. Each
milestone ends in something you can run.

## M0 — Scaffold (½ day)
- `pyproject.toml` (uv), package skeleton, DuckDB schema, Typer CLI stubs,
  Apache LICENSE, these docs. Seed `market_event` from `data/market_events.py`.
- **Demo**: `uv run mfrisk events` prints the event table.

## M1 — Catalog + classify (½ day)
- Parse AMFI `NAVAll.txt` → active schemes + SEBI category + ISIN.
- Diff vs mfapi full list → mark inactive (dead/merged).
- `classify.py` (category + name-keyword) → asset_class / is_equity / is_global.
- `plan_group.py` → logical funds with Direct/Regular Growth codes.
- **Demo**: `uv run mfrisk status` shows fund counts by asset class + active/dead.

## M2 — Fetcher (1 day)
- Async client: bounded concurrency, jittered spacing, backoff+jitter, adaptive
  429 cooldown, resumable `ingest_state`.
- Priority-ordered runner with **5K-scheme checkpoints**.
- **Demo**: `uv run mfrisk ingest --only equity` pulls the equity slice cleanly,
  no rate-limit hits; `status` shows progress.

## M3 — Metrics (1 day)
- Month-end resample, monthly returns, Sortino/Ulcer/Martin/MaxDD/CAGR/Sharpe.
- Per-window plan resolution (Direct ≤10Y / Regular >10Y).
- Unit tests vs synthetic series; cross-check one real fund.
- **Demo**: `uv run mfrisk compute` fills `metric`; query top-10 by Sortino 3Y.

## M4 — Microsite (1–1.5 days)
- FastAPI + HTMX rank view, fund detail with uPlot + event overlays, compare.
- **Demo**: `uv run mfrisk serve` → sort equity by Sortino/Ulcer per window.

## M5 — Full universe + cadence (0.5 day)
- Run ingest across **all** asset classes in priority order; refresh demo every
  5K funds (equity+global → hybrid → debt → multi-asset → rest).
- **Demo**: full universe rankable; status shows checkpoints.

## M6 — Polish (ongoing)
- `mfrisk refresh` daily incremental (AMFI delta + new NAVs only).
- Expand `market_events` via web research; optional T-bill RFR series.
- Optional: known-merger `merge_map`; CSV/Parquet export of `metric`.

## Open items / future (not v1)
- Time-varying risk-free rate from T-bill series.
- Benchmark-relative alpha / information ratio.
- Synthetic splicing across known fund mergers.
- Macro layer (data.gov.in / MoSPI) — deferred; this repo is MF-first.
